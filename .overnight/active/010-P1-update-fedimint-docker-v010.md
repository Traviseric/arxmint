# Update root docker-compose.yml to Fedimint v0.10.0

**Priority:** P1 (high)
**Source:** gap_analyzer P1 + OVERNIGHT_TASKS.md (ID: 9)
**Location:** `docker-compose.yml`

## Problem

The community generator (`lib/community-generator.ts`) outputs Docker Compose configs using Fedimint v0.10.0 images and its updated API, but the root `docker-compose.yml` still uses Fedimint v0.5.0 images. This version mismatch means a deployment generated by the tool runs different software than the root compose, creating inconsistency and making it impossible to test generated configs against the local stack.

## How to Fix

1. In `docker-compose.yml`, find the fedimint service definitions and update image versions:
   - Old: `fedimintd:v0.5.0` (or similar v0.5.x tag) → New: `fedimintd:v0.10.0`
   - Old: `fedimint-gateway:v0.5.0` → New: `fedimint-gateway:v0.10.0`
   - Old: `fedimint-guardian-ui:v0.5.0` → New: `fedimint-guardian-ui:v0.10.0`
2. Update ConnectorRegistry transport config to v0.10 API:
   - Check what API changes exist between v0.5.0 and v0.10.0 (check community-generator.ts for the v0.10.0 config structure it generates)
   - Update environment variables and volume mounts to match v0.10.0 format
3. Update `docker/` any override files that reference fedimint versions
4. Test that `docker compose up` still works (or at minimum document that it's been updated)

## Acceptance Criteria

- [ ] All Fedimint image references in `docker-compose.yml` use v0.10.0 tags
- [ ] Environment variable names match v0.10.0 API (compare with community-generator.ts output)
- [ ] `docker compose config` validates without errors
- [ ] Generated configs from `lib/community-generator.ts` match the root compose version
- [ ] `npm run build` passes (build itself doesn't depend on docker, but verify no import errors)

## Notes

Check `lib/community-generator.ts` for the exact image tags and environment variables it outputs for v0.10.0 — use those as the reference for what the root compose should match. The goal is version parity, not a specific version choice.
