# ADR Index

Architecture Decision Records (ADRs) capture durable engineering decisions.

Scope for required ADRs:

- Authentication and authorization model changes
- Payment and settlement protocol changes
- Data model and migration strategy changes
- Deployment topology and delivery strategy changes
- Security control posture changes

Naming convention:

- `ADR-YYYYMMDD-short-title.md`
