## What You'll Deploy

- **Mint backend:** Cashu mint (CDK) — or Fedimint federation (3+ guardians) for larger communities
- **Lightning:** LND node with neutrino light client
- **Privacy:** Ecash privacy by default (CoinJoin/PayJoin optional)
- **Monitoring:** Prometheus + Grafana dashboards
- **Agent commerce:** L402 + NUT-24 paywalls (optional)

## Deploy Your Own — 5 Steps

```
1. Provision a VPS (DigitalOcean, Hetzner, or similar)
2. Run ArxMint Community Generator → describe your community → download docker-compose.yml
3. docker compose up -d → LND syncs, mint starts, Grafana loads
4. Fund Lightning channels (min 1M sats inbound, 3+ channels)
5. Onboard founding merchants with QR codes and/or Numo NFC cards
```
